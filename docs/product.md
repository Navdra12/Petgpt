# Product

Goal: a small desktop pet that acts as a visual entry point to the user's
normal ChatGPT subscription without separate API billing.

MVP:
launch -> pet -> click -> ChatGPT bubble -> use normal ChatGPT -> Esc/click to
hide -> reopen with session preserved.

Later: animated characters, reaction states, polished speech bubble, multi-
monitor support, autostart, themes, and multiple pets.
